# App Preview video (~30 s): "Put your logo on any curve"

Specs for an Apple App Preview: 15–30 s, H.264 .mov/.mp4, portrait **886x1920** for iPhone 6.9" and **1200x1600** for iPad 13". It must show real in-app footage (titles and overlays are OK). Audio is optional, so use music only or none. Don't show device frames or hands. The first frame becomes the poster frame unless you choose another.

| Time | On screen (screen recording) | Overlay text |
|---|---|---|
| 0–3 s | The finished tumbler with the PEAK logo wrapped around it, slowly orbiting | **Your logo. Any curve.** |
| 3–7 s | "Choose a template" → tap **Import STL** → the tumbler model loads | Import any STL, OBJ or 3MF |
| 7–12 s | Tools → Add → pick the logo; it appears wrapped on the curve, then drag it up | Follows the surface, in one step |
| 12–17 s | Front/back → T+ Text → type "TRAIL CREW" in a bold font | Lettering, 120 fonts |
| 17–22 s | Emboss tab → tap **Invert relief**; the camera orbits close to show the raised pad | Emboss, deboss or invert |
| 22–27 s | Tap **Export STL** → the share sheet / save to Files | Print-ready STL for any slicer |
| 27–30 s | The hero tumbler again, then the app icon and name | **Caviot Studio** · No 3D modeling needed |

Recording on a real phone (best quality): use iOS Screen Recording from Control Center on an iPhone 16/17 Pro Max with a TestFlight build. Trim and add titles in iMovie or CapCut, then export at 886x1920 30 fps.
The draft rendered here (kept outside the repo) came from a browser simulation of the phone layout, so use it as a storyboard or placeholder. It uses the same app code (mobile/www), but use the real-device recording for the final version so the rendering matches iOS exactly.
